# weighted-grade-calculator-project

This project was an assignment completed around March of 2026. The goal was to create a console-based weighted grade calculator where the user could decide whether they wanted to input a single student or multiple students, sort all students, search for a specific student, or exit.

The program asks how many course components there are, and then proceeds to ask the user for the name, weight, and max point amount for each component. The user can then input the student(s) grades.
